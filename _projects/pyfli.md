[**PyFli**](https://pyfli.org) is an open-source Python package I authored and published on [PyPI](https://pypi.org/project/pyfli-lib/) for the unified, scalable processing and analysis of Fluorescence Lifetime Imaging (FLI) data.

It supports multiple acquisition methods — ICCD, SPAD, and TCSPC — and provides a range of analytical approaches, from traditional non-linear least squares fitting to deep-learning-based inference methods, all under a single, consistent interface.

**A new release is scheduled for August 31, 2026.** Check [pyfli.org](https://pyfli.org) for the latest documentation, or install the current release from [PyPI](https://pypi.org/project/pyfli-lib/):

```
pip install pyfli-lib
```
